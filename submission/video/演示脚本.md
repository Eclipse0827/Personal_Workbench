# 三分钟演示脚本

录屏前先准备：桌面版已安装、`data/` 里有几条待办（不要空数据），侧栏「设置与数据」里已配好一个模型（或保持规则引擎，画面上会标「规则引擎」）。
录制分辨率 1440×900 以上，鼠标移动放慢，不要出现通知弹窗。

| 时间 | 画面 | 旁白 / 打字 | 要点 |
|---|---|---|---|
| 0:00–0:12 | 屏幕上并排打开备忘录、番茄钟 App、PDF 阅读器、聊天窗口（示意即可，可用四张真实截图拼一格） | 「准备考研的人，一天里大概会开四五个工具。每件都做得不错，问题是它们互不相识。」 | 先把痛点立住，不解释功能 |
| 0:12–0:40 | 切到「概览」。鼠标依次划过：今日待办、本周专注、学习计划 | 「缓一缓只回答三个问题：今天还剩什么，这一周的时间花在哪，现在最适合进哪个模块。」 | 强调**没有**催促文案、没有连续打卡 |
| 0:40–1:10 | 进「待办与计划」。新建一条待办，挂到「考研 408」这个学习项目和「408 二轮」计划上 | 「任务可以挂到长期计划，也可以挂到学习项目。挂上去之后，它就不再是一条孤立的待办。」 | 展示归属，不是展示输入速度 |
| 1:10–1:40 | 进「专注」。选刚才那条待办 → 选 25 分钟 → 开始。计时走 5 秒后点右上角「浮到桌面」，窗口收成吸边小球，再拖回展开 | 「每一轮专注都绑一条具体的待办。结束之后，这 25 分钟知道自己是哪门课的。」 | 浮窗是重点，动作要慢 |
| 1:40–2:05 | 进「教材精读」。点开一本教材 → 展开章、节 → 点某一节的「生成讲义」 | 「教材不是上传一个 PDF 就开始问答。它先被拆成章、节，每一节单独生成讲义，回答只引用这一节的原文。」 | 讲清「拆章节」这件事 |
| 2:05–2:25 | 进「外刊阅读」。打开一篇文章 → 选中一个词 → 弹出释义 → 点「加入生词本」→ 切到「生词本」页看到这条 | 「外刊里查过的词自动进生词本，不用再开一个背单词 App。」 | 一次完整的查词动作 |
| 2:25–2:52 | 进「AI 整理空间」。输入一句「这周有四件事压着，我不知道先做哪个」→ 等回复 → 出现「问题梳理卡」→ 点「下一步可以先进 1 条」→ 出现「行动方案卡」→ 勾一条 → 点「加入待办」→ 切到待办页看到新任务 | 「它先梳理，不动手。你说想往下走，它才给方案；你勾了、确认了，才会变成待办。」 | **这一段是全片的重点，不要赶** |
| 2:52–3:00 | 三个图标并排：Windows / Android / 网页，右下角打出「数据只在本机，不上传」 | 「同一份代码，三种外壳。数据全部留在本机，没有账号，不上传。」 | 收尾一句，不要念功能列表 |

## 录制清单（照着勾）

- [ ] 演示数据已准备好，画面上不出现「测试教材」「UI 自测」这类字样
- [ ] 模型已配好，或明确保持规则引擎（画面会标注来源，不算缺陷）
- [ ] 浮窗动作录制成功（吸边 → 小球 → 拖回），失败就重录这一段
- [ ] AI 对话那段一次跑通；如果模型响应慢，剪掉等待，保留「输入 → 梳理卡 → 方案卡 → 确认」四步
- [ ] 全片不出现桌面通知、IME 候选框、个人信息
- [ ] 导出 1080p，文件名 `缓一缓-演示.mp4`，控制在 3 分钟内

## 备选：不录屏也能交
