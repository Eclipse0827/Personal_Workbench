功能架构

同一套服务端，三种外壳；数据只落在本机。不依赖数据库、不依赖前端框架、服务端运行时零第三方依赖。

三种外壳（同一份代码）

网页版浏览器直接打开
Node 内置 HTTP 服务
桌面版Electron 45
同一进程内可再开浮窗
安卓版Capacitor 8 + 内嵌 Node
离线可用，数据在私有目录
▼

表现层 · public/　约 2 万行，原生 JS，无框架

视图工作台 / 待办与计划 / 专注 / 学习项目 / 教材精读 / 外刊阅读 / AI 整理空间
状态与交互hash 路由、流式 Markdown、计时状态机（刷新不丢）
浏览器内能力PDF.js 取文字与书签、高亮批注、按字符偏移还原阅读位置
▼

服务端 · server/　约 1.6 万行，仅 Node 内置模块

编排层 · server.js只做参数校验与流程编排；REST 接口 + 静态文件
数据层 · db.js / models.js唯一持久化入口；字段白名单；软删除进回收站
领域模块projects / textbook / articles / focus-stats
AI 层 · ai.js / llm.js / tools.js规则 / Ollama / 远程三引擎可切；工具调用最多 3 轮
模型配置 · model-config.js多供应商、多模型、对话级 modelRef、Key 脱敏
本机能力 · ocr.jsWindows OCR 识别扫描版教材，含目录还原
▼

存储 · data/　一文件一条目，可读、可备份、可单条恢复

业务数据tasks / plans / projects / conversations / textbooks / articles / vocabulary
专注与记忆focus-active 唯一一份计时（网页与浮窗共用）/ focus-aliases / profile
底线不连云、不上传、不需要账号；Key 只存本机；删除进 .trash 可找回
